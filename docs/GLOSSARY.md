# 용어집

프로젝트 문서, 보고, 대화는 이 용어로 통일합니다. 오른쪽 열은 맵·코드에서 같은 대상을 가리키는 이름입니다.

## 공정 구역

| 용어 | 뜻 | 맵·코드 |
|---|---|---|
| **대기구역** | 바퀴가 없는 차체가 타이어 결합을 기다리는 구역 | `factory/vehicle_buffers` 왼쪽(+y), `LeftVehicleBuffer` |
| **결합구역** | B1에서 차체의 휠을 가조립하고 체결하는 구역 | 가운데 셀(파란 바닥), `DockPlate`, 스테이션 `FL/FR/RL/RR` |
| **출고구역** | 타이어 결합이 끝난 차량이 전방 출차하는 구역. 후속 버퍼 연결은 미확정 | A/B 실험의 출고 버퍼는 `RightVehicleBuffer` |

## 로봇 및 이송 설비

| 용어 | 뜻 | 맵·코드 |
|---|---|---|
| **타이어 장착 로봇** | 타이어를 차체에 장착하는 로봇팔 (좌우 각 1대, 바닥 고정) | Kawasaki RS080N + SCHUNK 트레드 클램프, `factory/mount_robots` (`LeftMountRobot` / `RightMountRobot`) |
| **너트 체결 로봇** | 너트를 체결하는 로봇팔 (좌우 각 1대, 바닥 고정) | Kawasaki RS080N + map_fasten 컴팩트 5축 헤드(235 mm), `factory/fasten_robots` (`LeftFastenRobot` / `RightFastenRobot`) |
| **AMR** | 차체를 공정 구역 사이로 옮기는 자율주행 이동 로봇 | `Carrier`, `DockedAMR`, `DockLift` |
| **타이어 공급 라인** | 1F에서 B1 픽업점까지 타이어를 보내는 경사·수평 공급 경로 | 로컬 시험 `LeftTieredFeed`, `RightTieredFeed`와 B1 `LeftFeed`, `RightFeed` |
| **인덱스 이동** | AMR이 차량을 휠베이스 2.720 m만큼 밀어 허브를 고정 작업점에 맞추는 이동. A→B와 B→C에서 수행 | `WHEELBASE`는 거리, `INDEX_TRAVEL`은 재생 이동 시간 |
| **나사선** | (정의 보완 필요) | 허브 스터드 M12×1.5 (`Stud_*`) |

## 정렬 기준

| 용어 | 뜻 | 맵·코드 |
|---|---|---|
| **허브 각도** | 허브의 나사 체결 구멍이 놓인 각도. 휠 체결 구멍을 맞출 때 기준 (차량 쪽) | `BOLT_ANGLES`, `Contact_<스테이션>` |
| **휠 각도** | 수직 방향 기준으로 휠이 기운 정도. 허브 각도에 맞춰 장착 방향을 정렬 (바퀴 쪽) | `Station.error` (deg) |

## 정렬·로봇 제어

| 용어 | 뜻 |
|---|---|
| **포즈 (Pose)** | 물체의 위치와 방향을 함께 나타내는 정보 |
| **6D 포즈 추정** | 물체의 3차원 위치(x, y, z)와 3축 회전 방향을 추정하는 기술. 휠·허브의 위치와 방향을 파악할 때 사용 |
| **좌표계 변환** | 카메라, 로봇, 차량 등 서로 다른 기준 좌표계의 위치·방향 정보를 변환하는 과정 |
| **체결 홀 패턴 분석** | 휠과 허브의 체결 구멍 배치·각도를 파악해 서로 맞는 위치를 찾는 과정 |
| **축 정렬** | 볼트와 체결 홀의 중심축이 같은 방향을 향하도록 맞추는 작업 |
| **역기구학 (IK)** | 로봇 베이스 기준의 목표 TCP 위치·자세를 만드는 관절각을 계산하는 방법 |
| **모션 플래닝** | 로봇이 목표까지 안전하게 이동하도록 경로를 계획하는 과정 |
| **정밀 위치 제어** | 목표 위치에 맞춰 로봇이나 공구를 세밀하게 이동·정지시키는 제어 |

## 비전 검사·차량 이송

| 용어 | 뜻 |
|---|---|
| **머신 비전** | 카메라 영상으로 물체의 위치, 상태, 불량 여부 등을 자동으로 판별하는 기술 |
| **객체 검출** | 영상에서 타이어나 휠 등 대상 물체의 위치와 영역을 찾아내는 기술 |
| **OCR** | 영상 속 문자·숫자를 인식하는 기술. 타이어 표기나 규격 확인에 활용 가능 |
| **AMR 내비게이션** | AMR이 주변 환경을 파악해 목적지까지 경로를 찾고 이동하는 기능 |
| **도킹 (Docking)** | AMR이 작업 위치에 정밀하게 접근해 정해진 위치·방향으로 정차하는 과정 |
| **리프트 (Lift)** | 차체를 들어 올리거나 높이를 맞추는 장치 또는 동작 |
| **리니어 축** | 로봇팔이나 장비의 작업 범위를 직선 방향으로 넓히는 이동축 |
| **충돌 회피** | 로봇, 차량, 설비가 서로 부딪히지 않도록 경로와 동작을 조정하는 기능 |
| **가림 (차폐)** | 그리퍼나 설비가 카메라 시야를 가려 검사 대상 일부가 보이지 않는 현상 |

## 로봇 협업·공정 안정화

| 용어 | 뜻 |
|---|---|
| **다중 로봇 협업** | 여러 로봇이 역할을 나눠 하나의 작업을 함께 수행하는 방식 |
| **동기화** | 여러 로봇의 동작 순서와 시작·완료 시점을 맞추는 제어 |
| **인터록 (Interlock)** | 특정 조건이 충족되지 않으면 다음 동작을 막아 오작동이나 위험을 예방하는 안전 조건 |
| **파지력** | 그리퍼가 휠이나 타이어를 잡고 유지하는 힘 |
| **삽입 오차 보정** | 볼트가 체결 홀에 들어갈 때 위치 오차를 감지해 접근 위치나 방향을 수정하는 과정 |

공정 순서와 작업점 기준은 [공정 시나리오](PROCESS_SCENARIO.md)에서 관리한다.
