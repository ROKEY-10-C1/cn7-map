# CN7 휠 조립 셀의 후면 컨베이어 배치와 산업안전 설계

2026-11-27 · Isaac Sim 통합 맵 설계 기록

차체 양쪽에 고정식 Kawasaki RS080N을 장착용과 체결용으로 한 대씩 배치한다. 타이어 공급 라인은 두 로봇의 뒤쪽으로 옮기고, 작업자 보행 통로는 안전펜스 바깥에 둔다. 이 문서의 검증 결과는 시뮬레이션 장면의 **정지 상태 배치**에 관한 것이다. 실제 설비의 안전 적합성을 판정하려면 하중을 포함한 운전 경로, 정지 성능 및 안전제어 기능을 별도로 검증해야 한다.

## 확정 공정과 검증 범위

공정은 [A/B/C 시나리오](PROCESS_SCENARIO.md)를 따른다. 1F 데크, 경사 컨베이어와 B1 픽업점은 적재 차량 스윕 외형과 분리해 배치한다. 로컬 시험의 0.185 m 구조물 여유와 2.503 m 공급 설비 여유는 충돌 검토 결과이며, 방호·인체 안전 이격이나 실설비 인증 기준으로 사용하지 않는다. 경사부 역주행·이탈·낙하, 지지대 간섭, 차량과 사람의 동시 진입, 병렬 로봇 작업과 보호 정지는 별도 검증 대상이다.

## A/B 당시 평면 배치

| 차체 중앙에서 바깥쪽으로 | 수정 전 | 반영한 배치 |
|---|---:|---:|
| 차체와 AMR 도킹 중심 | y = 0 | y = 0, 위치 A x = −0.45 m / 위치 B x = 2.27 m. B에서 앞범퍼와 타이어 분기 컨베이어 사이 0.54 m (ISO 13854 몸통 500 mm) |
| 장착용·체결용 RS080N 베이스 | y = ±2.50 m | y = ±2.50 m |
| 타이어 직선 컨베이어 중심 | y = ±1.19 m | **y = ±3.80 m** |
| 로봇 셀 측면 펜스 중심 | y = ±3.20 m | **y = ±5.25 m** |
| 셀 펜스 높이 | 1.46 m | **1.80 m** |
| 입고·출고 차량 버퍼 중심 | y = ±7.40 m | **y = ±9.69 m** |

차체에서 바깥쪽으로 **RS080N → 타이어 픽업 위치·컨베이어 → 셀 펜스 → 보행 통로 → 차량 버퍼**가 이어진다. ±는 좌우 대칭 좌표다. 장착용 베이스는 x = −0.33 m, 체결용 베이스는 x = 2.27 m에 둔다. 같은 쪽 두 베이스의 중심 간격은 2.60 m다.

기존 펜스 안에서는 대기 중인 로봇 외곽 뒤로 약 0.17 m만 남아 폭 0.67 m의 컨베이어를 넣을 수 없었다. 새 맵은 공급 분기에서 좌우 후면 라인으로 곡선을 연장했다. 픽업 위치와 불량 배출 경로도 함께 옮겼다. 버퍼와 AMR 경유점은 같은 배치 상수를 사용하며, 횡이송 시간표는 20초로 조정했다. y 좌표와 통로 폭은 이 셀의 설계값이다.

## A/B 당시 검증 결과와 안전 검토

| 항목 | 결과 |
|---|---|
| 모델·배치 | USD 장면에서 좌우 장착용 2대, 체결용 2대의 역할과 좌표를 확인했다. 픽업 라인과 펜스가 좌우 모두 로봇 바깥쪽에 있다. |
| 정지 상태 간격 | 대기 자세에서 같은 쪽 두 로봇의 공구 포함 경계 상자 사이 최소 간격은 **1.96 m**, 로봇과 공급 컨베이어 사이 최소 간격은 **0.45 m**다. 정비문 옆 비상정지 버튼 전면과 맞은편 버퍼 가드 사이의 유효 폭은 **1.55 m**다. |
| 로봇 작업 범위 | 후면 픽업 → 회전 → 허브 접근 → 후퇴의 전 구간을 실제 공구와 타이어 형상으로 검증해야 한다. 리플레이는 좌우 각각 x = 0.27 m에서 타이어를 집는다. 위치 A에서 전륜을 장착(걸기)만 한 뒤 첫 클램프를 열고 AMR을 x 방향으로 2.72 m 이송한다. 위치 B에서 전륜 체결과 후륜 장착을 동시에 하고 후륜을 체결한다. 같은 쪽 장착·체결 팔의 링크 중심선 간 최소 거리는 0.69 m(키프레임 0.1 s 간격 계산)이며, 실제 링크 외형 간격은 충돌 형상으로 다시 확인해야 한다. 좌우 픽업·들기·장착·체결의 대표 목표 자세는 URDF 관절 한계 안에서 해를 확인했다. |
| 이송과 출입 | 새 곡선에서 타이어가 걸리거나 이탈하는지, 차체 적재 상태의 AMR이 개구부를 지날 때 사람이 함께 진입할 수 있는지 시험해야 한다. 별도 Nav2 지도를 쓰는 경우 사용하는 지도와 버퍼 좌표도 새 USD에 맞춰야 한다. |
| 안전제어 | 맵의 광전자식 방호장치·정비문 인터록·비상정지 버튼은 배치 검토용 형상이다. 검출부터 실제 위험 동작 정지까지의 시간, 문을 닫거나 버튼을 해제한 뒤의 재기동 방지, 인원 잔류 시 기동 금지를 별도로 구현·시험해야 한다. |

방호장치의 최종 위치는 타이어를 든 상태에서 가장 멀리 움직이는 지점, 센서와 제어기의 응답시간, 로봇과 컨베이어의 정지시간을 바탕으로 정한다. 위험점에 사람이 도달하기 전에 위험 동작이 멈추는지를 확인한 뒤 현장 치수를 확정한다. [ISO 10218-2:2025 산업용 로봇 셀](https://www.iso.org/standard/73934.html) · [ISO 13855:2024 방호장치 위치 선정](https://www.iso.org/standard/80590.html)

## 과거 4륜 공정 리플레이 기록

아래 시각은 당시 재생 시험 기록이다. 새 A/B/C 공정의 시간이나 완료 판정에는 적용하지 않는다. 41.9초에 전륜이 안착하고, 체결과 지지대 후퇴 뒤 55.4초에 첫 클램프가 열려 차체 이송을 시작한다. 6초 이송 후 두 번째 클램프가 닫히고 63.4초에 재도킹이 완료된다. 83.8초에 후륜이 안착하고 101.3초에 출고를 시작한다.

일반 주문 4건과 혼합 규격·첫 불량 주입 주문 4건의 생성 장면에서 공용 픽업 좌표, 클램프 순서, 차량 위치, 안착 시 공급 휠과 장착 휠의 월드 좌표 일치를 확인했다. 이 결과는 키프레임 공정 검증이다. 라이브 PhysX의 재도킹 제어, 실제 파지·이송과 충돌 없는 연속 관절 경로, 안전정지 기능은 후속 검증 대상이다.
