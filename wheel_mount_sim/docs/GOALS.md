# 장착 기능 목표와 합격 기준

좌전륜(및 같은 쪽 뒷바퀴)을 작업대에서 집어 허브에 거는 장착 공정의 **목표값**이다. 값마다 근거를 적었고,
근거가 업계 관행·추정인 값은 그렇게 표시했다. 현재 값은 `run.py --scenario nominal`(시드 1) 결과다.

## 1. 공정 시간 (택트)

| 항목 | 값 | 근거 |
|---|---|---|
| 완성차 라인 택트 | **60 s/대** | 대량 생산 조립 라인에서 흔히 쓰는 55~60 s (도요타 조지타운 약 60 s 등, 업계 자료) |
| 장착로봇 1대가 맡는 바퀴 | 한쪽 앞·뒤 2개/대 | 양쪽에 장착로봇 1대씩 (고정 설치) 가정 |
| 차 들어오고 나가기·대기 | 10 s | 가정 (AMR 도킹·위치 확인) |
| **바퀴 1개 장착 목표** | **≤ 25 s** (집기 → 장착 → 다음 집기 위치 복귀) | (60 − 10) / 2 |

### 단계별 시간 (시뮬레이션)

`run.py`(기본, 관절 속도 35 %) → `run.py --fast`(단축 프로필). 시드 1, 둘 다 `RESULT mounted`.

| 단계 | 기본 (s) | `--fast` (s) | `--fast`에서 바꾼 것 |
|---|---|---|---|
| 집기 위로 접근 + 내려가기 | 5.7 | 3.4 | 관절 속도 50 %, 내려가기 0.25 m/s |
| 조 닫기 (카탈로그 1.09 s) + 안정 | 1.7 | 1.3 | 안정 대기 0.6 → 0.2 s |
| 들기 | 2.8 | 1.1 | 0.25 m/s |
| 세우며 허브 축으로 운반 | 6.0 | 4.9 | **세우기 구간은 35 % 유지** (아래 참고) |
| 비전 정렬 | 2.8 (2회) | 1.4 (1회) | 1회로 충분 (0.10 mm < 목표 0.30 mm) |
| 삽입 | 8.1 | 3.6 | 자유 접근 50 mm/s, 힘 제어 20 mm/s |
| 힘 빼기 + 조 열기 | 2.6 | 1.5 | 조가 약 38 mm 열린 0.9 s 뒤 후퇴 시작 |
| 허브 축 따라 후퇴 | 3.0 | 3.2 | 경유점(허브 바깥 450 mm)까지, 0.2 m/s |
| 다음 집기 위치 복귀 | (미포함) | 2.6 | 관절 이동 |
| **합계 (바퀴 1개)** | 약 37 | **22.3** | **목표 ≤ 25 s 만족** |

**속도를 올리며 드러난 제약 (시뮬레이션으로 확인)**
- 세우기 구간 관절 속도 70 % → 그리퍼 안에서 바퀴가 **38.9 mm 미끄러짐**, 50 % → **24.7 mm**, 35 % → 타이어-슈 미끄러짐 없음
  (림-그리퍼 오프셋 1.3 mm는 세운 뒤 림 무게 89 N이 타이어 옆면 강성 65 N/mm를 누른 처짐 1.37 mm와 일치). 슈 두 개가 수평 지름
  근처에서 잡는 구조라 회전 관성력에 약하다 → **세우기 구간은 35 %로 제한**.
- 조를 0.45 s만 열고 후퇴하면 슈가 타이어를 끌어 바퀴가 다시 밀려 나옴 → 0.9 s.
- 후퇴 뒤 관절 공간으로 바로 복귀하면 그리퍼가 방금 단 타이어를 침(슈 접촉력 최대 149 kN) → **허브 축 따라 경유점까지 후퇴 후 복귀**.

## 2. 단계별 합격 기준 (바퀴 1개)

| 단계 | 지표 | 목표 | 근거 | 현재 |
|---|---|---|---|---|
| 집기·운반 | 타이어-슈 미끄러짐 (림 처짐 제외) | ≤ 0.5 mm | 허브 앞에서 비전으로 다시 재므로 위치보다 **놓침 위험** 지표. 세운 뒤 림 처짐(약 1.4 mm, 타이어 옆면 강성)은 정상 | 들기 0.004 mm, 운반 후 림 오프셋 1.31 mm(처짐) ✅ |
| 집기·운반 | 바퀴 떨어짐 | 0 건 | 안전 | 0 ✅ |
| 운반·삽입 | 차체·휠하우스·캘리퍼 접촉력 | **0 N** | 도장·부품 손상은 바로 불량 (품질) | 0 N ✅ |
| 삽입 전 정렬 | 구멍-스터드 중심 어긋남 | ≤ 0.30 mm | 반경 틈 0.70 mm − 스터드 위치 공차 0.05 − PCD 공차 0.025 − 구멍 공차(미확인, 0.1 가정) ≈ 0.5 mm, 안전율 약 1.7 | 0.03 mm ✅ |
| 삽입 전 정렬 | 위상(볼트 각도) 오차 | ≤ 0.30° | PCD 반지름 57 mm에서 0.30 mm | 0.0° ✅ |
| 삽입 전 정렬 | 바퀴-허브 축 기울기 | ≤ 0.30° | 파일럿 틈 0.086 mm × 2 / 물림 12 mm = 0.8°, 안전율 약 2.7 | 0.009° ✅ |
| 삽입 | 누르는 힘 (설정) / 최대 | 145 N / ≤ 400 N | 셀 프레스 한계 145 N, 400 N은 로봇 충돌 감지 수준(추정)·스터드 나사 손상 방지 | 145 / 146 N ✅ |
| 안착 | 누른 상태 허브면 간격 | ≤ 0.5 mm | 나머지는 너트가 당김 | 0.32 mm ✅ |
| 놓은 뒤 (체결 인계) | 허브면 간격 | ≤ 2.0 mm | 체결 인계 문서(`wheel_cell/HANDOVER.md`) 완전 안착 후 놓음 중앙값 1.97 mm | 1.4 mm ✅ |
| 놓은 뒤 | 기울기 | ≤ 1.6° | 같은 문서 최댓값 1.56° (5축 동시 체결 성립 범위) | 1.1° ✅ |
| 놓은 뒤 | 파일럿 물림 유지 | 간격 < 12 mm | 빠지면 위쪽 스터드가 구멍 안으로 숨어 5축 체결 불가 (같은 문서) | 유지 ✅ |
| 놓은 뒤 | 가장 짧은 스터드 돌출 (웹 밖) | ≥ 5 mm | M12×1.5 너트가 2산(3 mm) 이상 물리고 소켓이 잡을 여유 | 약 13 mm (계산) ✅ |
| 전체 | 바퀴 1개 공정 시간 | ≤ 25 s | 1절 | 22.3 s (`--fast`) ✅ |
| 전체 | 첫 시도 성공률 | ≥ 99.5 % | 자동화 공정의 일반적인 목표 수준(업계 관행, 출처 없음) | 1/1 (검증 필요) |

### 성공률 검증 방법

성공률 99.5 %를 95 % 신뢰로 말하려면 **연속 600회 무실패**가 필요하다(3의 규칙: 3/600 = 0.5 %).
시드(바퀴 놓인 각도·허브 각도·측정 노이즈)와 추정 물리값 범위(슈 마찰 0.35~0.9, 허브 마찰 0.3~0.61)를 섞어 돌린다.
1회 약 5분이므로 우선 시드 20개 × 마찰 3단계 = 60회로 실패 유형을 찾고, 그다음 600회를 돌린다.

## 3. 세부 제어 과제 (우선순위)

1. ~~공정 시간 37 s → 25 s~~ → **22.3 s 달성** (`--fast`). 남은 여유 2.7 s.
2. **강건성**: 시드·마찰 범위 반복 실행으로 실패 유형 찾기.
3. **놓은 뒤 지표 자동 기록**: 스터드별 돌출 길이·면 간격을 로그에 추가 (지금은 계산값).
