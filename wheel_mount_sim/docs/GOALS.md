# 장착 기능 목표와 합격 기준

좌전륜(및 같은 쪽 뒷바퀴)을 작업대에서 집어 허브에 거는 장착 공정의 **목표값**이다. 값마다 근거를 적었고,
근거가 업계 관행·추정인 값은 그렇게 표시했다.

현재 값의 기준 (2026-11-28 저녁, 최신):
- **셀 기준, 고정 셀·카메라 비전 없음 (4.0절)**: 팀 조립 셀 맵(`scene/`)에서 `mount_control.py --car --car-dynamic`(`MOUNT_FIXED=1`)로 차량 한 대의 바퀴 4개를 장착한 결과 2회(바퀴 8개).
  - 허브 공차 0, 타이어 각도 고정
  - 위치는 티칭값, 정렬은 그리퍼의 레이저 변위 센서
  - 차체 다이내믹, A에서 앞바퀴 → 가짜 AMR 이동 → B에서 뒷바퀴
- 이전 기준(4.1~4.3절)은 기록으로 남긴다. 단독 시뮬 `run.py`의 단계별 시간(1절 표)은 2026-11-27 값이다.

## 1. 공정 시간 (택트)

| 항목 | 값 | 근거 |
|---|---|---|
| 완성차 라인 택트 | **60 s/대** | 대량 생산 조립 라인에서 흔히 쓰는 55~60 s (도요타 조지타운 약 60 s 등, 업계 자료) |
| 장착로봇 1대가 맡는 바퀴 | 한쪽 앞·뒤 2개/대 | 양쪽에 장착로봇 1대씩 (고정 설치) 가정 |
| 차 들어오고 나가기·대기 | 10 s | 가정 (AMR 도킹·위치 확인) |
| **바퀴 1개 장착 목표** | **≤ 25 s** (집기 → 장착 → 다음 집기 위치 복귀) | (60 − 10) / 2 |

| 비전 정렬 | 2.8 (2회) | 1.4 (1회) | 1회로 충분 (0.10 mm < 목표 0.30 mm) |

**속도를 올리며 드러난 제약 (시뮬레이션으로 확인)**
- 세우기 구간 관절 속도 70 % → 그리퍼 안에서 바퀴가 **38.9 mm 미끄러짐**, 50 % → **24.7 mm**, 35 % → 타이어-슈 미끄러짐 없음
  (림-그리퍼 오프셋 1.3 mm는 세운 뒤 림 무게 89 N이 당시 타이어 옆면 강성 65 N/mm를 누른 처짐 1.37 mm와 일치. 11/28 측벽 값을 강체 링 문헌 값 700 N/mm로 고친 뒤 처짐은 약 0.1~0.2 mm). 슈 두 개가 수평 지름
  근처에서 잡는 구조라 회전 관성력에 약하다 → **세우기 구간은 35 %로 제한**.
- 조를 0.45 s만 열고 후퇴하면 슈가 타이어를 끌어 바퀴가 다시 밀려 나옴 → 0.9 s.
- 후퇴 뒤 관절 공간으로 바로 복귀하면 그리퍼가 방금 단 타이어를 침(슈 접촉력 최대 149 kN) → **허브 축 따라 경유점까지 후퇴 후 복귀**.

### 성공률 검증 방법

성공률 99.5 %를 95 % 신뢰로 말하려면 **연속 600회 무실패**가 필요하다(3의 규칙: 3/600 = 0.5 %).
시드(바퀴 놓인 각도·허브 각도·측정 노이즈)와 추정 물리값 범위(슈 마찰 0.35~0.9, 허브 마찰 0.3~0.61)를 섞어 돌린다.
1회 약 5분이므로 우선 시드 20개 × 마찰 3단계 = 60회로 실패 유형을 찾고, 그다음 600회를 돌린다.

## 3. 남은 과제 (우선순위, 2026-11-28 저녁 기준)

1. **실패 처리 (다음 작업)**: 실패를 센서로 인식하고 유형별로 재시도한다.
   - 집기: 조임 힘 없음
   - 삽입: 걸림, 파일럿에서 안 빠짐
   - 놓은 뒤: 간격·기울기 초과
   - 공급: 타이어 시간 초과

   일부러 실패를 일으켜(타이어 위치 틀어짐, 정렬 어긋남 등) 복구율을 잰다. 지금은 대부분 알람으로 멈추기만 한다.
2. **공정 시간 28~32 s → 25 s**: 1절 셀 단계별 시간 참고.
   - 정렬: 레이저 1회 + 이동 중 측정
   - 안착 판정 창 줄이기
   - 놓기 단계(힘 빼기·푸셔·조 열기) 겹치기
   - 회전과 세우기 겹치기
3. **성공률 검증**: 8바퀴는 표본이 적다. 간이 셀(`bench_insert.py`, 4개씩)과 셀 전체를 섞어 수십~수백 회로 실패 유형을 찾는다.
4. **실제 부품 선정**: 웹 푸셔(공압 실린더 + 비례 레귤레이터 150 → 30 N), 레이저 변위 센서 5개(Keyence IL급), 조 중간 정지 밸브. 그리퍼 질량·하중 재확인.
5. **실측이 필요한 모델값**: 파일럿·보어 지름(지금 틈 0.08 mm 가정), 타이어 측벽 축 방향 강성(문헌 범위 0.45~2 MN/m 중 0.7 MN/m 사용), 패드·허브 마찰.
6. **ROS 2 분리**: 팀 합의 뒤. 순서·인식·계획 노드 분리(`cell_mount_ros2.py` 1차본 있음).
7. **비전 → 머신러닝**: 고정 셀 가정(허브 공차 0, 타이어 각도 고정)을 풀고, AMR·타이어 위치 변화를 비전과 학습으로 흡수한다.
