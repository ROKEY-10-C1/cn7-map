# 체결팀 전달: 장착 직후 바퀴 상태와 요청 (2026-11-27)

장착로봇(`wheel_mount_sim`, 조립 셀 맵)이 바퀴를 허브에 끝까지 끼우고 놓은 뒤, 너트 없이 걸려 있는 바퀴의 상태다.
장착 쪽에서는 더 줄일 수 없어서, **체결 헤드가 너트를 물리기 전에 바퀴를 허브면으로 밀어 세우는 동작**을 요청한다.

## 1. 놓은 뒤 바퀴 상태 (seed 42, `output/cell/final2`)

| | 왼쪽 앞 | 오른쪽 앞 |
|---|---|---|
| 누른 상태 간격 (놓기 전) | 0.0 mm (완전 안착, 134 N) | 0.0 mm (133 N) |
| 놓은 뒤 허브면-장착면 간격 (중심) | 2.25 mm | 2.11 mm |
| 놓은 뒤 기울기 | 1.61° | 1.52° |

| 장착면이 닿는 곳 | 아래쪽 가장자리 | 같음 |
| 파일럿 | 물려 있음 (빠지지 않음) | 같음 |
| 구멍-스터드 위상 | 오차 0.06° 이내 | 같음 |

팀 인계 문서(`wheel_cell/HANDOVER.md`: 간격 중앙값 1.97 mm, 기울기 최대 1.56°)와 같은 현상이다.

## 2. 왜 기우나

- CN7 휠 ET46: 바퀴+타이어 무게중심(17.1 kg)이 장착면보다 46 mm 안쪽.
- 놓으면 장착면 아래 가장자리를 축으로 위쪽이 바깥으로 넘어가려 함: 모멘트 17.1 × 9.81 × 0.046 = **7.7 N·m**.
- 보어(67.1 mm)와 파일럿(66.94 mm)의 반경 틈 0.09 mm가 이 기울기를 약 1.1~1.6°에서 막는다.
- 즉 시뮬 오류가 아니라 너트 없이 걸린 바퀴의 실제 거동이고, 장착 쪽 동작(천천히 놓기 등)으로는 바뀌지 않았다 (시험함).

## 3. 요청: 체결 헤드가 밀어 세운 뒤 너트 체결

1. 헤드는 허브 축 방향으로 접근한다 (바퀴 면 방향 아님: 바퀴는 1.5~1.6° 기울어 있음).
2. 소켓(또는 너트)이 스터드에 들어간 뒤, 헤드가 바퀴를 허브면 쪽으로 민다.
   - 바퀴를 세우는 데 필요한 힘 (계산): 5개 너트로 고르게 밀면 약 **103 N**, 위쪽만 밀면 약 59 N.
   - 마찰·여유를 고려해 **150 N 이상** 권장 (장착 때 145 N으로 완전 안착 확인).
3. 미는 상태에서 너트를 물리고 5개 모두 안착(스너그)할 때까지 유지한 뒤 본 체결.
4. 확인 기준 제안: 체결 전 허브면-장착면 간격 ≤ 0.5 mm, 기울기 ≤ 0.3°.
