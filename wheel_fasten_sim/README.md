# CN7 B→C 너트 체결 시험

저장소 루트에서 실행한다. GUI는 완료 또는 실패 프레임에서 일시정지한다.

```bash
~/isaacsim/python.sh -B wheel_fasten_sim/main.py
~/isaacsim/python.sh -B wheel_fasten_sim/main.py --headless
```

단계별 시험은 `--through FR` → `--through front` → `--through reload` → `--through move` → `--through full` 순으로 실행할 수 있다. `--through FL`은 기존 좌전륜 단독 시험이다. `reload`는 B에 정차한 상태에서 재장전까지, `move`는 C 정차와 재장전 확인까지 진행한다. 콘솔 `RESULT`에서 단계·측정값·실패 원인을 확인할 수 있다. 헤드리스 실행은 성공 시 0, 나머지는 1을 반환한다.

- **일시정지 → Play**는 같은 프레임과 제어 상태에서 이어서 실행한다.
- **Stop → Play**는 원본 USD를 다시 열어 B 정차점에서 시작한다. 미완료 시도는 `STOPPED`로 진단 로그에 남는다. 프로그램을 종료하고 다시 실행할 때도 같은 초기 상태에서 시작한다.

## 공정과 모듈

1. B에서 FL·FR 컨트롤러를 동시에 갱신한다. 후륜은 기존 림·링 타이어 구조를 런타임에 후륜 허브에 생성해 가결합을 모사한다.
2. 관측한 스터드 축과 배열에 정렬하고, 실제 스핀들 회전수에 맞춰 피치 1.5 mm/rev로 전진한다. 안착 검증 후 소켓 관절을 해제하고 너트를 허브 Fixed Joint에 결합한다. 체결 이후 휠을 현재 자세에서 허브에 고정하는 관절로 조임 효과를 모사한다. 두 로봇의 PARK 복귀와 후륜 가결합 상태를 확인한다.
3. C까지 AMR에 힘을 가하는 동안 좌우가 매거진에서 재장전한다. 후륜 가결합 유지 조건을 통과하면 현재 자세에 이송 유지 관절을 건다. 실제 포트와 소켓을 정렬한 뒤 공용 너트 에셋으로 새 배치를 생성한다. 이동 중 PhysX 강체 좌표로 차량·리프트·네 휠·타이어·전륜 너트의 상대 위치를 확인한다.
4. C 정차와 재장전 완료가 확인되면 이송 유지 관절을 해제한다. 안정화 후 실제 RL·RR 허브 자세를 읽어 같은 컨트롤러로 체결한다. 후퇴와 너트 유지 확인까지 끝나면 전체 `DONE`을 반환한다.

`main.py`가 World와 하나의 물리 루프를 관리한다. `FastenTask.observe()`는 USD에서 자세를 읽고, `FastenController.update(dt)`는 IK와 드라이브를 갱신한다. `FastenCell`은 독립 시험의 공정 인터록을 관리한다. 통합 코드에서는 `wheel_cell/`을 Python 검색 경로에 두고, 로봇별 컨트롤러의 `request_fasten(corner)`, `request_reload()`, `result()`를 사용한다. 초기 체결을 외부에서 시작하려면 `autostart=False`로 생성한다. 물리 단위는 m·s이고 내부 각도는 rad, USD 드라이브는 deg·deg/s, USD 쿼터니언은 wxyz 순서다.

## 검증과 한계

| 단계 | Isaac Sim 5.1 검증 |
|---|---|
| FR 단독 | 너트 5개 결합, 최대 안착 오차 0.173 mm, PARK 복귀 |
| B 전륜 동시 | FL·FR 너트 10개 결합 및 양쪽 PARK 복귀 |
| B 정차 재장전 | 좌우 새 너트 5개씩 장전 및 PARK 복귀 |
| B→C 이동과 재장전 | 약 8.58초 병렬 수행. C 위치 4.990 m, 통과 영역과의 최소 횡방향 여유 727 mm |
| 이동 중 상대 위치 | 차량–리프트 0.018 mm, 리프트–차대 0.290 mm, 휠–허브 0.015 mm, 타이어–림 0.869 mm, 너트–허브 0.077 mm 이하 |
| 전체 헤드리스·GUI | 두 환경 모두 물리 시간 69.50초에 `DONE`. 전·후륜 20개 결합 및 PARK, 최대 후륜 안착 오차 0.195 mm 이하 |
| GUI 재개·재시작 | Pause에서 물리 프레임 유지, Stop 후 이전 허브 관절과 장전 배치가 없는 새 세션 확인 |

- Isaac Sim 5.1, CPU PhysX 240 Hz에서 시험한다. 원본 USD와 공용 에셋은 변경하지 않으며 런타임 변경은 세션에만 기록한다.
- 휠을 접촉 상태로만 둔 첫 이동에서는 우전륜 너트와 타이어의 상대 편차가 커져 중단됐다. 시스템 체결 완료 시 휠–허브 조임 관절을 추가한 구성에서 이동 기준을 충족했다. GUI 재시작 시험에서는 후륜 타이어–림 편차도 기준을 넘은 사례가 있어, B→C 중 후륜 가결합 유지 관절을 사용하는 구성으로 바꿨다.
- 후륜 공급과 재장전은 시스템 모사다. 실제 장착 로봇 동작, 나사산 접촉, 체결 토크 및 휠 고정력은 검증 범위 밖이다.
- 이동 간섭 검사는 로봇·매거진·장전 너트의 경계와 AMR 통과 영역의 횡방향 분리를 확인한다. 다른 배치나 설비까지 포함하는 충돌 경로 계획은 별도 범위다.
