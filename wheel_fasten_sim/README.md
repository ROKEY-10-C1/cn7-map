# B 정차점 FL 너트 체결 시험

저장소 루트에서 실행한다. GUI 시험은 자동으로 시작하며, 완료 또는 실패 프레임에서 일시정지한다. 같은 초기 상태로 다시 시험하려면 새로 실행한다.

```bash
~/isaacsim/python.sh -B wheel_fasten_sim/main.py
~/isaacsim/python.sh -B wheel_fasten_sim/main.py --headless
```

콘솔의 `RESULT`에 최종 상태와 측정값이 나온다. 헤드리스 실행은 `DONE`에서 종료 코드 0, 그 외 상태에서 1을 반환한다.

## 시퀀스

1. 물리 안정화 후 소켓에 너트 5개가 장전되어 있는지 확인한다. 실제 허브·휠 자세와 스터드 돌출량으로 접근 가능 여부를 판단한다.
2. PARK에서 수직 경유 자세를 거쳐 허브 바깥쪽으로 접근한다. 관측한 허브 축과 다섯 스터드의 회전 위상을 맞춘다. 너트 위치·공구 축·패턴 오차가 허용 범위에 들어오면 회전을 시작한다.
3. 플랜지에 상대적인 로터 위상을 누적해 실제 회전수를 센다. 가장 느린 축의 진행률에 맞춰 피치 1.5 mm/rev로 공통 플랜지를 전진시키고, 다섯 너트의 시스템 안착 위치와 회전수를 검사한다.
4. 허브와 너트 사이의 Fixed Joint 다섯 개를 런타임에 생성한다. 같은 프레임에서 소켓 유지 관절을 해제하고 허브 관절을 활성화한다.
5. TCP가 휠 축 방향으로 충분히 이격되면 PARK로 복귀한다. 너트 5개의 허브 상대 위치와 관절 관계를 확인한 후 `DONE`을 반환한다. 정렬·IK·체결 실패 또는 타임아웃 시 스핀들을 멈추고 실패 단계와 원인을 반환한다.

## 코드와 데이터 흐름

- `main.py`는 SimulationApp과 World를 초기화하고 USD의 물리 주기에 맞춰 공통 루프를 실행한다. 구동 명령과 관절 변경은 USD 세션 레이어에 기록된다.
- `fastening.py`의 `FastenTask.observe()`는 USD에서 World Pose 스냅샷을 읽는다. `get_world_pose()`는 관측 어댑터의 진입점이다. 허브 좌표, 스터드 팁, 너트 및 로터 자세는 한 캐시로 읽는다.
- `FastenController.update(dt)`는 한 물리 프레임의 상태를 갱신한다. `solve()`는 World 목표를 베이스 좌표로 변환한 뒤 기존 RS080N URDF 기반 감쇠 최소제곱 IK를 사용한다. 관절 드라이브가 로봇을 움직이며 관측한 위치를 다음 명령에 반영한다. `lock()`은 관측된 허브 상대 좌표로 Fixed Joint를 구성한다.
- 내부 길이는 m, 각도는 rad, 속도 드라이브는 deg/s다. USD 쿼터니언은 wxyz 순서다. 통합 코드에서 재사용할 때는 `wheel_cell/`을 Python 모듈 검색 경로에 두고 공통 루프에서 컨트롤러를 업데이트한다.

## 검증과 한계

- Isaac Sim 5.1, 240 Hz, B 정차점 FL. 헤드리스와 GUI에서 `DONE`까지 확인했다. 최종 GUI 시험의 물리 시간은 25.96초였다. 너트 5개가 목표 16.00회전 대비 약 15.98회전했고, 최대 안착 오차는 약 0.20 mm였다. TCP 약 91 mm 이격과 PARK 복귀 후 너트 유지도 확인했다.
- 안정화된 전륜은 허브에서 약 2.18 mm 벌어지고 1.57° 기울었다. 시험은 스터드 노출을 확인한 뒤 명목 허브 기준으로 시스템 안착을 수행한다. 휠이 체결 하중으로 당겨지는 거동, 나사산 접촉, 체결 토크와 휠 고정력은 검증 범위 밖이다.
- 접근·후퇴 경유 자세는 FL 장면에서 시험했다. 다른 배치에 적용할 때는 경로 간섭 검증이 필요하다. 좌우 병렬 체결, AMR 인덱싱, 재장전 및 후륜 작업은 후속 범위다.
